How to use

Levels (top of palette):

  • Click a level name to switch the editor's current level.
  • Double-click the name to rename it.
  • Click the × on a row to delete that level (cannot delete the last one).
  • Click + New Level to add a level after the current one (with a default empty layout).

Tools:

  • Ground — click+drag horizontally across the ground row to mark a segment.
  • Platform — click+drag any direction to draw a brick platform.
  • Food — click to drop. 1=coke, 2=bigmac.
  • Enemy — click to spawn. Patrol defaults to ±64px. 0–3 for type: journalist/scientist/girl/lobbyist.
  • Power-up — click. 1=MAGA Hat, 2=Censor Bar, 3=Classified Docs.
  • Flag — click to set flag X position.
  • Spawn — click to set player start.
  • Select — click an existing object to edit it in the Inspector panel.
  • Erase — click an existing object to remove it.

Snap conventions: all coordinates snap to the 32-px tile grid.

  • Food / enemies / powerups: top-left of a tile.
  • Flag: left edge of a tile.
  • Player start: top-left of a tile.
  • Ground: inclusive tile indices.

Undo / Redo: Cmd/Ctrl+Z undo, Cmd/Ctrl+⇧+Z (or Y) redo. Every place, erase, drag, level add/delete, and inspector change is on the stack.

Edit patterns:

  • Shift+click = erase (any tool).
  • Right-mouse drag = pan.
  • Mouse wheel = zoom (centered on cursor).
  • Home = fit world in view; Ctrl+Home = jump to spawn; Ctrl+End = jump to flag.
  • Arrow keys = pan by 320 world px; Page Up/Down = zoom by 1.15x.
  • Minimap (bottom-right) click or drag to jump the view.
  • ⊡ Fit / ▶ Spawn / ⚑ Flag buttons in the toolbar.
  • The game reads the same JSON via GameScene.preload(); missing level.json falls back to a hardcoded FALLBACK_LEVEL in game.js.
